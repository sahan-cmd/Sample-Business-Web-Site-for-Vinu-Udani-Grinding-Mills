හැඳින්වීම (Introduction)

මෙම ලේඛනය හරහා ඔබගේ නව වෙබ් අඩවියේ (Web App) දත්ත සමුදාය (Database) සැකසී ඇති ආකාරය සරලව විස්තර කරනු ලබයි. දත්ත සමුදායක් යනු අපගේ පද්ධතියේ ඇති සියලුම තොරතුරු (පරිශීලකයන්, භාණ්ඩ, ඇණවුම්) ආරක්ෂිතව ගබඩා කරන ස්ථානයයි.

1. ප්‍රධාන වගු (Main Tables / Collections)

මෙම පද්ධතිය සඳහා ප්‍රධාන වගු 4ක් යෝජනා කෙරේ:

👥 Users (පරිශීලකයන්)

පද්ධතියට ලියාපදිංචි වන පාරිභෝගිකයින්ගේ විස්තර මෙහි අඩංගු වේ.

Field (ක්ෂේත්‍රය) Description (විස්තරය)
user_id අනන්‍ය අංකය (Primary Key)
name පාරිභෝගිකයාගේ නම
email විද්‍යුත් තැපෑල (Login සඳහා)
password_hash රහස් පදය (ආරක්ෂිතව)
auth_provider Google / Facebook / Custom ද යන්න
address බඩු ගෙනවිත් දිය යුතු ලිපිනය

📦 Products (භාණ්ඩ / කුළු බඩු)

ඔබ විකුණන සියලුම කුළු බඩු වල විස්තර මෙහි ඇත.

Field (ක්ෂේත්‍රය) Description (විස්තරය)
product_id භාණ්ඩයේ අනන්‍ය අංකය
name භාණ්ඩයේ නම (උදා: Chilli Powder)
price මිල
weight බර (උදා: 100g)
image_url පින්තූරයේ Link එක
category වර්ගය (Spices, Flour, ආදී)

🛒 Orders (ඇණවුම්)

පාරිභෝගිකයන් විසින් කරන ලද මුළු මිලදී ගැනීම් (POS හරහා හෝ Online) මෙහි සටහන් වේ.

Field (ක්ෂේත්‍රය) Description (විස්තරය)
order_id ඇණවුමේ අංකය
user_id ඇණවුම දැමූ පුද්ගලයා (Foreign Key)
total_amount මුළු මුදල
discount_applied 5% ක වට්ටමක් ලැබුනාද යන්න (True/False)
status Pending, Shipped, Delivered
created_at ඇණවුම දැමූ වේලාව

🛍️ OrderItems (ඇණවුම් කළ අයිතම)

එක් ඇණවුමක ඇතුළත් වන භාණ්ඩ මොනවාද යන්න මෙහි දැක්වේ.

Field (ක්ෂේත්‍රය) Description (විස්තරය)
item_id අනන්‍ය අංකය
order_id අදාළ ඇණවුමේ අංකය
product_id මිලදී ගත් භාණ්ඩයේ අංකය
quantity ප්‍රමාණය (Quantity)
price_at_purchase මිලදී ගත් අවස්ථාවේ මිල

කොහොමද මේක වැඩ කරන්නේ? (How it works logic)

  • Login වීම: පරිශීලකයෙක් Google හෝ Custom විදිහට Login වුනාම, ඔහුගේ විස්තර Users වගුවේ සටහන් වේ.
  • භාණ්ඩ තේරීම: Website එක load වෙද්දි Products වගුවේ තියන දත්ත (පින්තූර, මිල) UI එකට ලබා දෙයි.
  • Discount (වට්ටම්): Shopping Cart එකේ Item 3 ක් හෝ ඊට වඩා වැඩි නම්, පද්ධතිය ස්වයංක්‍රීයව (Automatic) Total එකෙන් 5% ක් අඩු කරයි.
  • Checkout / POS Buy: පාරිභෝගිකයා Buy Button එක එබූ පසු, Orders වගුවට අලුත් රෙකෝඩ් එකක් සහ OrderItems වලට අදාළ භාණ්ඩ ටික ඇතුලත් වේ.
